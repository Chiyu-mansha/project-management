## 第 1 页 · 封面

- 标题：校园活动智能通知&报名助理
- 副标题：活动发布 + AI 推文 模块
- 落款：POD-1 · 成员2

## 第 2 页 · 我做了什么（模块总览）

- 活动发布全链路：CRUD + 五态状态机 + 角色权限
- AI 推文：多风格生成 + 二次润色（经独立 AI 网关）
- 封面图：上传 / 移除（回到默认 emoji）
- 学生端：活动广场卡片流、详情页推文展示
- 关键接口表：
  - `POST/GET/PUT /api/activities`
  - `POST /api/activities/{id}/generate-article`
  - `POST /api/activities/{id}/polish-article`
  - `POST /api/upload`

## 第 3 页 · 核心链路（流程图 + 现场演示入口）

```
发布者登录
  → 填活动信息（标题/类型/时间/地点/简介/报名条件/综测/组队）
  → 上传封面（可移除回默认）
  → AI 生成推文（简约/活泼/正式）→ 不满意可润色
  → 发布
学生端：活动广场卡片流 → 详情推文 → 报名
```

## 第 4 页 · 技术亮点① —— 活动状态机

- 五态：`draft → published → ongoing → finished`，`cancelled` 终态
- **时间自动流转**：到开始时间自动 `ongoing`，到结束时间自动 `finished`
- 状态只能单向前进，后端强校验，避免乱跳
- 取消后禁止新报名、保留历史（与 POD-2/POD-3 对齐）

## 第 5 页 · 技术亮点② —— AI 网关 + Prompt 工程

- 各 POD **不直连大模型**，统一走 `gateway/` 的 `/api/ai/*`
- 后端查活动表拼完整信息 → 发给网关 → 返回 Markdown
- 结构化输出：主标题 / 亮点 / 时间地点 / 活动详情 / 报名须知，500~800 字
- 喂入 `标签`、`报名条件`、`综测加分` 等字段，素材更足
- 网关不可用**自动降级**，不中断发布

## 第 6 页 · 技术亮点③ —— 封面与角色

- 封面：上传存本地 `/uploads`，前端相对路径 + vite proxy
- 「移除」封面 → 卡片回默认 emoji 兜底
- 角色分离：发布者侧边栏 / 学生顶栏，路由守卫拦截越权
