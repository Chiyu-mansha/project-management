# 答辩演示脚本（口播稿）—— 活动发布 + AI 推文

> 现场演示约 2 分钟，照着念即可。

---

【开场】我是 POD-1 成员2，负责**活动发布 + AI 推文**这一块。核心解决的是「社团/竞赛负责人发活动麻烦、写推文费劲」的痛点。

【演示·发布】先看发布端。我用发布者账号登录，进「活动发布」填活动信息——标题、类型、时间、地点、简介、报名条件、综测加分、组队人数，这些字段都是为后续报名和推荐服务的。

【演示·封面】封面可以上传，传错了点「移除」就能回到默认，保存后活动广场的卡片会用默认 emoji 兜底。

【演示·AI 推文】重点看 AI 推文：选「活泼」风格点生成，后端会去查活动的完整信息，拼成 prompt 发给 AI 网关，返回一篇带 emoji、分小节的 Markdown 推文；不满意还能「润色」改写。

【演示·状态机】这个活动的状态是五态状态机，到开始时间会自动从「已发布」变成「进行中」，到结束时间自动「已结束」，不用人工手动改。

【演示·学生端】切到学生端，活动广场能看到卡片流，点进详情就是刚才那篇推文，往下就是 POD-2 的报名入口。

【收尾】我这边已经合入 main，和 POD-2 报名、POD-3 凭证都对齐了。谢谢。
